# telemedice1

A modern, full-stack Telemedicine and Healthcare Consultation Platform.

## 🌟 Overview
Telemedicine is a comprehensive healthcare platform connecting patients with certified medical professionals. It supports real-time appointment scheduling, direct doctor-patient messaging, email verification, and full-featured administrative control.

## 🚀 Key Features
- **Patient Portal**: Search and filter doctors by specialization, book and manage appointments, receive digital prescriptions, and chat in real-time.
- **Doctor Portal**: Set consultation availability, manage patient appointments, track earnings, and review medical records.
- **Admin Dashboard**: Comprehensive platform metrics, doctor verification, user management, and system administration.
- **Real-time Communication**: Instant messaging powered by Socket.io.
- **Secure Authentication & OTP**: JWT authentication with email OTP verification.

## 🛠️ Tech Stack
- **Frontend**: React 19, Vite, Tailwind CSS, Lucide Icons, React Router
- **Backend**: Node.js, Express 5, MongoDB (Mongoose), Socket.io, JWT, Nodemailer / Brevo
